How It Works

🧠 reason blocks

AI classifies webhooks into categories (urgent, billing, technical, security, etc.) using declarative goal/constraints/examples.

📈 evolve blocks

Tracks classification accuracy over time. When accuracy drops below threshold, triggers retraining.

📋 contract blocks

Validates webhook payload structure with natural language rules compiled to type-safe validators.

🔀 intent routing

Auto-discovers handlers by naming convention: create_webhook → POST, list_webhook → GET, etc.
